# T110 — CHANGELOG мовчить про десять комітів публічного API

**Статус:** не почато.
**Серйозність:** Medium — документ не порожній, а **застарілий**, що гірше: він виглядає веденим.
**Джерело:** `git log --oneline $(git log -1 --format=%H -- CHANGELOG.md)..HEAD -- docs/USAGE.md`
— знайдено під час T105, коли `plan-defense` спитав про rollback і публікацію.

## Що не так

`CHANGELOG.md` сам заявляє: «Формат: людською мовою, найновіше зверху. Версія —
`packages/sdk/package.json`». Остання версія в ньому — **0.2.0 від 2026-08-26**, і це ж число
стоїть у `package.json`. Відтоді `docs/USAGE.md` змінювали **десять комітів**, і серед них не
дрібниці:

| Коміт | Що змінилось у публічному API |
|---|---|
| `8c14a7a` | `searchAll` — **новий публічний метод** |
| `8a1c156`, `ca87950` | `initialExpand` і `initialExpand.revealNodeId` — нова конфігурація |
| `8264339` | окремий канал «сцену не намальовано, і ось чому» (`RenderFailure`) |
| `f933b84`, `ede3e0d`, `901f9aa` | `renderer: 'auto'` змінив форму (T98) |
| `c205618`, `33afe59` | **контракт `setData` змінився**: виграє останній запит, витіснений мовчить (T103) |
| `e1150c4` | семантика відкоту мутаторів (T104) |

Хост, що читає CHANGELOG, щоб зрозуміти, чи можна оновлюватись, дізнається з нього рівно нічого
про останні два тижні — включно зі зміненою семантикою методу, який кличуть на кожен рух камери.

## Чому це не полагодили в T105

T105 додав свій запис під `## Не випущено` (барель, `OrgHierarchyError`, §15 USAGE). Дописати за
нього ще десять чужих записів означало б **реконструювати їх заднім числом** з пам'яті про інші
задачі й підписати чужою роботою один коміт. Борг названий окремо саме тому.

## Що зробити

1. Пройти десять комітів і дописати відсутні записи в `## Не випущено` — по джерелу
   (диф + звіт задачі), а не по пам'яті.
2. Вирішити версію: накопичене тягне щонайменше на `0.3.0` (зміна контракту `setData` +
   прибрані експорти). Бамп — рішення людини.
3. ⚠️ **Розглянути гейт.** `check-docs.mjs` уже стереже три речі про доку; четверта могла б
   бути «`docs/USAGE.md` змінився, а `CHANGELOG.md` — ні». Але це евристика, не факт: не кожна
   правка USAGE є зміною контракту. Спершу вирішити, чи хибні спрацювання дешевші за мовчання
   — гейт, який кричить вовк, вимикають.

## Чого не робити

Не переписувати `0.2.0` заднім числом: він випущений і датований.
