# T132 — dev-tools-панель бібліотеки: налаштування SDK наживо в хості

**Пріоритет:** P2 · **Статус:** 🔵 не почато · **потребує `spec-flow`** (нова публічна поверхня)
**Рішення власника 2026-11-05:** інструмент налаштування й порівняння варіантів SDK **належить бібліотеці**
і працює «з коробки»; хост (`cassiopeia-admin-ui`) його **не будує**. Демо — не цільове середовище.

## Мета

Власник порівнює варіанти поведінки SDK (перший — refit камери після collapse/expand, T131) **у живому
хості, на тій самій картинці**: та сама камера, ті самі розкриті гілки. Перестворення діаграми це ламає.

## Межа

- **Бібліотека:** панель (DOM у контейнері діаграми), перелік налаштувань, перемикання наживо через
  runtime-сетери, дефолти — з SDK (для `staffRefitOnToggle` — `computeStaffFit`, рівні колишнім
  значенням демо).
- **Хост:** лише вмикає одним прапорцем у конфігу, напр. `devtools: import.meta.env.DEV`.
  Рішення «DEV чи прод» — хоста за прецедентом
  [ADR-0001](../../docs/adr/0001-test-anchor-overlay-gate-belongs-to-the-host.md) (SDK не знає оточення).

## Залежності

- [T131](./T131-staff-refit-after-expand-in-sdk.md) — опція `staffRefitOnToggle` **і runtime-сетер** до неї.

## Рішення власника (2026-11-05)

1. **Вмикання — прапорець `devtools?: boolean` в `OrgHierarchyConfig`.** Окремого входу немає.
2. **Перший зріз — не лише `staffRefitOnToggle`, а й інші вже наявні опції SDK.**
   - **Бачить лише адмін.** Роль знає тільки хост, тож хост передає `devtools: user.isAdmin`
     (за потреби `&& import.meta.env.DEV`). Бібліотека ролей не знає й не перевіряє. Прецедент — ADR-0001:
     «кому показати» вирішує хост, «що й як» робить бібліотека.
   - **Вигляд — як TanStack Router Devtools / RHF DevTools:** плаваюча кнопка-значок у куті контейнера,
     клік відкриває панель, що закривається. Код цих бібліотек не копіювати
     (лише описаний патерн, пам'ять `no-verbatim-third-party-code`).
3. **Панель показує поточні значення** й має **скидання до дефолтів SDK** (окремо для кожної опції й для всіх).

## Рішення агента (на перевірку в spec-flow)

4. **Нульова вартість для не-адміна:** панель вантажиться окремим чанком (dynamic `import()`) лише коли
   `devtools: true`; без прапорця її код не виконується й не потрапляє в основний чанк. Панель стоїть
   у проді (адміни), тож це вимога, а не оптимізація.
5. **Без React:** прапорець живе в ядровому конфігу, а React у SDK — optional peer (`./react`),
   тож панель — чистий DOM.

## Відкриті питання для spec-flow

- Повний перелік опцій першого зрізу: які з наявних опцій SDK можна безпечно міняти наживо (потрібен
  runtime-сетер на кожну) і які вимагають перестворення (їх показати read-only з позначкою)?
- Чи зберігати вибір адміна між перезавантаженнями (localStorage) чи лише на сесію?
