# T85 — Борг лінтера: 20 правил вимкнено, щоб гейт став зеленим сьогодні

**Пріоритет:** P2 · **Статус:** 🔵 не почато
**Підстава:** `chore/oxlint-oxfmt` — oxlint зайшов у CI; ці правила вимкнені, щоб не блокувати.

---

## Чому вимкнено, а не виправлено

Перший прогін oxlint по репо дав **866 порушень**. Виправляти їх усі в одному коміті означало б
непрочитаний диф на сотні місць. Тому гейт увімкнено **зеленим**: усе, що лишилось увімкненим,
перевіряється машиною вже зараз; усе, що вимкнено, перелічено тут із числом.

**Правило не можна вимкнути мовчки.** Кожен рядок нижче має або число (борг), або причину
(правило нам не підходить).

## Вимкнено як борг — вмикати по одному

| Правило | Порушень | Природа |
|---|---|---|
| `require-await` | 90 | `async` без `await`. Часто навмисно: публічний API обіцяє проміс |
| `unicorn/consistent-function-scoping` | 31 | вкладені функції, які можна підняти |
| `no-negated-condition` + `unicorn/no-negated-condition` | 20 | читабельність |
| `no-shadow` | 10 | затінення імен |
| `unicorn/no-object-as-default-parameter` | 7 | об'єкт як дефолт параметра |
| `no-promise-executor-return` | 5 | повернення з виконавця проміса |
| `unicorn/no-array-callback-reference` | 5 | `map(fn)` замість `map((x) => fn(x))` |
| решта (14 правил) | по 1–4 | дрібні, зібрані в `.oxlintrc.json` |

## Вимкнено НЕ як борг — правило нам шкідливе

| Правило | Чому |
|---|---|
| `unicorn/no-array-fill-with-reference-type` | 🔴 **хибні спрацювання**: усі 27 випадків — це `Graphics.fill({…})` з Pixi, а не `Array.prototype.fill`. Правило не розрізняє графічний API |
| `unicorn/no-array-reverse` | 🔴 автофікс міняє **поведінку**: `reverse()` (на місці) → `toReversed()` (копія). Плюс `toReversed` немає в нашій `lib` |
| `unicorn/prefer-code-point` | 🔴 автофікс міняє **результат**: `charCodeAt` → `codePointAt` дає інше число для сурогатних пар і може віддати `undefined`. У нас це хеш кольору аватара — кольори б поїхали |
| `unicorn/no-array-sort` | 🔴 автофікс пропонує `toSorted()` — сортування на місці стає копією |
| `max-lines`, `max-lines-per-function`, `no-inline-comments`, `no-underscore-dangle` | стилістика, яку тут судить рев'ю за `work/CODING_STANDARDS.md`, а не машина |
| стилістичні `unicorn/prefer-*` (dom-node, query-selector, at, string-replace-all) | чистий смак, нульова ціна помилки |

## Що вже виправлено цим заходом

- **41 мертвий імпорт/змінна** прибрані (`no-unused-vars` лишається **увімкненим**)
- ~350 порушень зникли автофіксом; типи чисті, 696 + 61 тестів зелені

## Готово, коли
