# T89 — Кулінг сцени по в'юпорту: його немає взагалі

## Факт

`grep` по `packages/sdk/src/render/` не дає ані `cull`, ані `renderable = false`. Тобто **жоден**
об'єкт сцени не виключається з обходу за тим, що він за межами екрана.

## Чесна оцінка, наскільки це болить

Агент назвав це «найдешевшою перемогою», і тут варто вповільнитись: **у нас інша ситуація, ніж
у React Flow**. Їм кулінг критичний, бо вони тримають **весь** граф. Ми тримаємо **вікно**
(639 боксів на `Staff · 1M`), тобто масштаб уже обмежений матеріалізацією, а не кулінгом.
Плюс `T84` зробив рендер on-demand — у спокої ми не малюємо взагалі.

Тож виграш реальний, але **не той порядок**, що в них. Перш ніж робити — зміряти: скільки
коштує кадр із 639 об'єктами проти кадру з ~78 видимими. Без цього числа задача не має ваги.

## Що переноситься з їхнього коду

**Захист від виродженого боксу** — `isEdgeVisible` (`system/utils/edges/general.ts:69-88`)
штучно розширює нульовий бокс на 1 px, інакше перетин із в'юпортом ніколи не спрацьовує.
🔴 **Для нас це критичніше, ніж для них:** наші ортогональні ребра вироджені **завжди** —
горизонтальний сегмент має нульову висоту. Кулінг ребер без цього захисту сховає всі
горизонтальні сегменти.
