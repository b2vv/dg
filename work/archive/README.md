# work/archive — завершені задачі

Сюди переїжджає задача з `work/tasks/`, коли вона **закрита**: критерії виконані, зміни в `main`.

**Вказівники, а не копії.** Рядок на задачу: що зроблено, яким PR/комітом закрито, де живе
результат. Копія тексту задачі розійшлася б з кодом і почала б брехати; мертвий вказівник видно.

**Переїзд, а не видалення.** Видалена задача забирає з собою слід рішення — чому зробили саме так
і що розглядали натомість.

## ⚠️ Це не кореневий `archive/`

| Тека | Що там |
|---|---|
| `work/archive/` (ця) | **завершені задачі** — вказівники |
| `/archive/` у корені репо | **legacy-код**: `legacy-ts/`, `legacy-web-rspack/` — знесені реалізації |

Різні речі з однаковим ім'ям. Кореневий `archive/` — не мірник і не черга робіт; він у
`## Не мірник` маніфесту.

## Формат рядка

```
- **T42 — назва задачі** → закрито PR #57 (`a1b2c3d`), результат у `packages/sdk/src/export/`.
  Чому так: <одне речення>. Відкинуто: <що саме й чому>.
```
