**Підхід, який я почав (відкочено, щоб лишити дерево зеленим):** малювати found-маркер у

  MouseEvent) + **власник дивиться на телефоні/ngrok**. Пікселі агент НЕ бачить.
- **ngrok**: `https://24c9-95-158-47-241.ngrok-free.app/?tab=staff-alpha` (підняв власник; якщо впав —
  `! ngrok http 3000`, URL із `curl -s http://127.0.0.1:4040/api/tunnels`).
- **Hover НЕ чіпає card border**: `borderColor=''` ревертить до `currentColor` = `--text:#e2e8f0`
  (styles.css), а не до бордера картки → малював білий ring на всіх. Тому hover тільки opacity+лінії.
- **Collapse = setData, НЕ reload**: reload робив dispose+recreate → flash. setData re-лейаутить на

  collapse підміняє geom + promote.sync(). Авто-fitView ПРИБРАНО (мис-рахував до far 0.15).
- **data-staff-pos = position-id** (не person-id ref.id) — для матчингу hover/found з лініями (fromId/toId).
- **Тест-раннер = rstest** (`@rstest/core`), НЕ vitest. `npm run test -w @org-hierarchy/sdk -- <filter>`.
  Rust: `cd packages/core && cargo test`. `timeout` на macOS немає.
