## BLOCKING
B1. **occupy на off-grid (best-effort) → паніка.** Кожне ребро (й fail=1) окуповується (:157 add на всіх). best_effort-точки мають off-grid `my` → yi(my)=None. У JS .get(undefined)→NaN-ключ = тихо нічого не пише (беззбитково). У Rust unwrap() на xi/yi → ПАНІКА саме на деградованому шляху, на який спирається рядок 16/AC. Дизайн T5 не описує обробку None. Вимога: occupy/release ПРОПУСКАЄ сегмент, якщо будь-який кінець не лягає на grid-лінію (= беззбиткова JS-поведінка), не unwrap.
B2. **Пропущено драйвер сцени → критерій tasks:26 невимірюваний.** Запропонований T5 додає лише Occupancy+occupy/release+cost-терми+&param. Без порту sort+route-then-occupy (:156-157) Occupancy ніколи не заповнюється між ребрами — cost-терми fire лише у hand-made unit-фікстурах, а «row 6 (S4) 0 перетинів» (tasks:26) НЕМОЖЛИВО навіть виміряти (нема ф-ції, що маршрутизує всю сцену). Дизайн мусить: (а) явно вмістити single-pass драйвер у T5 (rip-up :158 → T6), і (б) ДОВЕСТИ, що S4→0 досяжне single-pass; якщо S4 потребує rip-up — критерій належить T6, а не T5 (межа tasks:26/27 хибна).
B3. **Ключ node-мап.** Текст дизайну «node_h/edge_h[j*(nx-1)+i]» двозначний: node_h/node_v МУСЯТЬ бути за j*nx+i (повний node-index), лише edge_h за j*(nx-1)+i. Якщо node-мапи заключити за j*(nx-1)+i, cost.get(nn) ніколи не збігається → 4000-терм мертвий, S4 не збирається, а empty-occ T4-тести лишаються зелені (баг невидимий). Зафіксувати явно: node-range інклюзивний [i1..=i2]/[j1..=j2], edge-range верх-ексклюзивний.

## NON-BLOCKING (документувати / перевірити)
N1. **Недопустимість евристики (point 4).** .15-знижка робить реальну вартість ребра < len → Manhattan ПЕРЕоцінює → A* НЕ оптимальний і дає більше re-expansion. Це паритет із мокапом — СВІДОМО, документувати як відоме, не баг. Термінація тримається (g лише спадає, скінченні стани, cost≥0, ITER_CAP 250k), детермінізм тримається (seq-tie-break з T4). Перф-ризик AC9: бенчмарк мусить ганяти СЦЕНИ З ЗАПОВНЕНОЮ occ (не порожньою) — більше ітерацій.
N2. **Детермінізм-гейт (AC8).** cost робить лише .get + fo/ow = предикати існування (порядок Vec байдужий). Безпечно ДОКИ ніхто не ІТЕРУЄ по Occupancy-HashMap (std RandomState недетермінований). Явна заборона: не ітерувати occ-мапи; якщо треба серіалізація/дебаг — сортувати ключі.
N3. **Симетрія release.** rem = один indexOf per coverage, occupy = один push. Симетрично ЛИШЕ бо A* дає простий (ациклічний) шлях → кожен node з'являється раз → у межах однієї мапи ключ пушиться раз (кут: nV раз + nH раз, різні мапи). Задокументувати це припущення; якщо маршрут колись само-торкнеться вузла в тій самій орієнтації — десинх. Для rip-up (T6 rem→add) round-trip чистий за цим припущенням.
N4. **Сенс T5-unit (point 8).** T5-unit має асертити: (a) occupy пише очікувані ключі; (b) друге ребро за ВЖЕ заповненої occ дивертиться на паралельну доріжку (6000 спрацював); (c) release повертає occ у pre-стан (round-trip). Повний S4 0/0 — інтеграційно (драйвер + можливо T6). Зелений empty-occ T4-тест ≠ покриття T5 (пам'ять «асерт істинний без фічі»).
N5. **Підтвердження сигнатури (point 7).** Додати 9-й param &Occupancy до astar_route (вже #[allow(too_many_arguments)]) — правильний шов, не дубль-ф-ція. Empty Occupancy::default() у 5 T4-тестах зберігає їх сенс: cost редукується до len+turn (ідентично :780). ✓
