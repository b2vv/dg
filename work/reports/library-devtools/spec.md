# T132 — spec: dev-tools-панель бібліотеки

**Статус:** чернетка для GATE 1 · 2026-11-05 · таска [`T132`](../../tasks/T132-library-devtools-panel.md)
**Цільове середовище:** хост `cassiopeia-admin-ui` (ШПС на dg). Демо — не ціль.

## 1. Проблема

Власник хоче порівнювати варіанти поведінки SDK **у живому хості, на тій самій картинці**. Перший такий
варіант — refit камери після collapse/expand ([T131](../../tasks/T131-staff-refit-after-expand-in-sdk.md),
`staffRefitOnToggle`, `646e58c`). Сьогодні це можна зробити лише так: змінити конфіг у коді хоста,
перезібрати й перестворити діаграму. При цьому губиться камера й розкриті гілки, тож порівнюються дві
різні сцени.

Інструмент для цього належить **бібліотеці** (рішення власника): хост його не будує, лише вмикає.
Причина та сама, що в аудиті межі (`work/reports/library-boundary-audit/_wip-review.md`): що робить
демо або хост поверх SDK, те іншим споживачам не дістається.

## 2. Сценарії користувача

| # | Хто | Дія | Очікування |
|---|---|---|---|
| S1 | адмін | відкриває сторінку хоста з діаграмою | у куті контейнера діаграми — плаваюча кнопка-значок dev-tools |
| S2 | не-адмін | відкриває ту саму сторінку | нічого не бачить; код панелі не завантажено |
| S3 | адмін | клікає значок | відкривається панель: опції SDK, поточні значення, позначка «змінено» проти дефолту SDK |
| S4 | адмін | перемикає `staffRefitOnToggle` → згортає гілку | новий варіант діє одразу; камера й розкриті гілки **ті самі**, що до перемикання |
| S5 | адмін | «скинути» одну опцію / «скинути все» | значення повертаються до дефолтів SDK |
| S6 | адмін | перезавантажує сторінку | його вибір відновлюється (localStorage) |
| S7 | будь-хто | хост вимикає `devtools` (не адмін на тому ж браузері) | збережені вибори адміна **не діють** |
| S8 | адмін | закриває панель | лишається лише значок; діаграма працює як звичайно |

## 3. Критерії приймання

- **AC1 — вмикання.** `OrgHierarchyConfig.devtools?: boolean`, дефолт `false`. Хост вирішує, кому
  показати (`devtools: user.isAdmin`); бібліотека ролей не знає (прецедент ADR-0001).
- **AC2 — нульова вартість.** При `devtools !== true` код панелі не виконується й не входить в основний
  чанк SDK (вантажиться окремим чанком лише при `true`). Поведінка діаграми й DOM контейнера — без змін.
- **AC3 — вигляд.** Патерн TanStack Router Devtools / RHF DevTools: плаваюча кнопка-значок у куті
  контейнера діаграми → панель, що відкривається/закривається. Не перекриває взаємодію з діаграмою,
  коли закрита. Код цих бібліотек не копіюється — лише патерн.
- **AC4 — перелік.** Панель показує обрані опції SDK (§5 «перелік першого зрізу»), для кожної —
  поточне значення, дефолт SDK і позначку «змінено».
- **AC5 — наживо.** Зміна опції в панелі застосовується до **тієї самої** діаграми без перестворення:
  камера, виділення й розкриті гілки зберігаються. Для кожної редагованої опції SDK має **окремий**
  публічний runtime-сетер (його ж може кликати й хост) — перелік у §6.
- **AC6 — дефолти з SDK.** Дефолти беруться з SDK, а не хардкодяться в панелі (для `staffRefitOnToggle` —
  `computeStaffFit`). «Скинути» = повернути дефолт SDK; «скинути все» — усі опції разом.
- **AC7 — збереження.** Вибір адміна зберігається в localStorage і застосовується при наступному
  створенні діаграми — **лише коли `devtools: true`** (S7: спільний браузер не передає вибір не-адміну).
- **AC8 — без React.** Панель — чистий DOM: React у SDK лише optional peer (`./react`), а прапорець
  живе в ядровому конфігу.
- **AC9 — документація.** `devtools`, нові сетери, ключ localStorage й правило пріоритету —
  в `docs/USAGE.md` (`check:docs` зелений).

## 4. Поза межами

- Перевірка ролей / автентифікація — це хост.
- Редагування `data`, `mappers`, `callbacks`, воркерів, `renderer`, медіа — не налаштування поведінки.
- Демо-специфічні сценарії й прапорці.
- Експорт / імпорт набору налаштувань (може прийти пізніше).

## 5. Рішення GATE 1 (власник, 2026-11-05 — раунд 1 «yes go»)

1. **Пріоритет:** збережений вибір адміна перекриває конфіг хоста. Зберігається лише **дельта від
   конфігу хоста**. «Скинути» опцію = прибрати дельту → значення з **конфігу хоста**; «скинути все» =
   очистити всі дельти. Дефолт SDK показується довідково (і є базою, коли хост опцію не передав).
2. **Перший зріз — лише дешеві опції** (SDK читає їх у момент використання):
   `staffRefitOnToggle`, `motionBlur`, `viewportSettleMs`, `lodThresholds`, `theme`.
   Дорогі (`render.*` staff-прапорці, `staffLayout`, `orgLayout`) **не показуються**; кандидат на зріз 2.
3. **Ключ localStorage — один на origin** (`org-hierarchy:devtools`). Розширення прапорця до
   `{ storageKey }` — адитивно, коли з'явиться друга dg-діаграма на сайті (нині одна, ФАКТ:
   `use-positions-diagram.ts:242` у хості).
4. **Значок — фіксовано низ-праворуч** контейнера; **відкритість панелі пам'ятається** в тому ж записі.

## 6. Рішення GATE 1, раунд 2 (власник, 2026-11-05)

5. **Окремий публічний сетер на кожну «живу» опцію:** `setStaffRefitOnToggle(v)`, `setMotionBlur(v)`,
   `setViewportSettleMs(ms)`, `setLodThresholds(t)`; `theme` — наявний `setTheme`. Кожен — у `docs/USAGE.md`.
6. **`devtools` читається лише при створенні діаграми.** Хост, якщо треба, перестворює діаграму.
   Динамічне вмикання — пізніше, адитивно.

**GATE 1 — пройдено:** відкритих розвилок у специфікації не лишилось. Далі — `plan.md` (крок 4).
