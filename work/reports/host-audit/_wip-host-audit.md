## ПРАВИЛО — merge-семантика (дефінітивно, з коду .NET, не з переказу)

Метод злиття (`PositionFactory.cs:173-216`), псевдокодом:
- каскад підлеглих: `primary.subordinates := primary.subordinates ++ merged.subordinates`
- union носіїв: окрема функція об'єднання за особою (date-reconciliation)
- 🔴 неочевидно: `primary.leadConnections := merged.leadConnections`
  — виживаюча позиція бере зв'язки **зливаної**, не свої
- каскад за ідентифікатором еквівалентності: усі позиції з тим самим ідентифікатором →
  статус «скасовано» + видалення

Endpoint: `PositionModule.cs:36` `POST {externalId}/merge/` → `externalId→PrimaryPositionId`,
сучасний фронтенд шле `currentPositionId` як `externalId` → позиція під курсором виживає.
