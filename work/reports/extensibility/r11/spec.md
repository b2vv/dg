# R11 — Правила ліній з обгортками (obstacle-регіони) — spec

**Статус:** spec. Гілка `feat/extensibility`. Джерело: ROADMAP §R11 (owner 2026-11-02, розвилки вирішено). GATE-1 з роадмапу.
Пов'язано: staff-link-routing A* у Rust (пам'ять), ADR-0002 edgePort.

## Проблема / межа
Owner: усі прямокутні обгортки (grid-collapsed сиблінги T113, ШПС staff-chrome, груп/департамент-контейнери, будь-який
node-box) трактуються **уніфіковано** як obstacle-регіони для роутера — один плоский список, не спецкейси. **Grounded:**
obstacles у коді ВЖЕ = кожна картка (`staffEdgeGeometry.ts:334-335`) + `frames`/`zones` у `StaffRoutingInput`
(`staffRouterV2.ts`), routing у **Rust** (`staff_router.rs`, `staff_clearance.rs`). R11 = **розширення списку** прямокутниками
обгорток + коректність (self-exclusion) + докінг до collapsed-обгортки.

## Межа R11 (РОБИТЬ / НЕ)
- **РОБИТЬ (роадмап декомпозиція a/c/d/b):**
  - (a) кожна обгортка → прямокутник у множину перешкод, нарівні з node-box (плоский список).
  - (c) clearance: перешкоди роздуваються на маржу (одна константа F11.2, індустрійна норма) — коридор.
  - (d) **self-exclusion (КОРЕКТНІСТЬ, не смак):** власні кінцівки лінії + **весь ланцюг предків-обгорток** виключаються
    з перешкод для ЦІЄЇ лінії (інакше лінія зсередини не вийде зі свого контейнера). Nesting (e) обходиться автоматично за (d).
  - (b) докінг: до expanded-ноди — edgePort як зараз (ADR-0002); до **collapsed-grid** — док до **краю обгортки**.
- **routing лишається в Rust-ядрі** (інваріант Б2: хост стилить полілінію, не шлях).
- **НЕ робить:** бандлінг (F11.1 ВИРІШЕНО: fan/порти, не бандл); хост-API стилю (окремо); D3-часозмінність — перешкоди
  **семплюються на settle** (не щокадру; лінії стадуються — D3 GATE 1 Q3, уже так); clearance-тюнінг (дефолт прийнято).

## User scenarios
1. Лінія між нодами різних департаментів-контейнерів огинає чужі контейнери (вони — перешкоди), але виходить зі свого
   (self-exclusion предків).
2. Лінія до collapsed-grid сиблінгів докається до краю обгортки (ноди всередині не адресуються згорнутими).
3. Лінії не труться об борт обгортки (clearance-маржа).
4. Під час D3-переходу обгортки анімуються як бокси, лінії згасають; на settle — reroute проти фінальної геометрії.

## Acceptance (чернетка)
- AC1: обгортки (frames/zones/collapsed-grid-боксы) входять у множину перешкод роутера нарівні з node-box (один список).
- AC2: self-exclusion — лінія виходить зі свого контейнера (власні кінцівки + ланцюг предків-обгорток виключені); НЕ
  застрягає всередині. Регресійний кейс: вкладені департамент⊃grid⊃ноди.
- AC3: clearance-маржа роздуває перешкоди (лінії не торкаються борту); одна константа.
- AC4: докінг до collapsed-обгортки — на край обгортки (edge-port), не до внутрішніх нод.
- AC5: routing лишається в Rust; TS-вхід лише додає прямокутники обгорток у `StaffRoutingInput`; cargo test зелений.
- AC6: без обгорток у вході — поведінка як зараз (node-box-only перешкоди); паритет.

## Out of scope / Open
- Бандлінг (вирішено проти). Хост-стиль полілінії (окремо). D3-часозмінність (settle-sampling, уже так).
- ⚠️ Межа WASM↔TS: якщо `types.rs` (StaffRoutingInput) розширюється обгортками → **перегенерувати `rust-types.ts`**
  (`npm run build:wasm`), контракт явний (конституція). Координатор робить build:wasm (спільний wasm-pkg) обережно.
- Owner-review (при пуші): clearance-константа F11.2 (емпіричний тюнінг пізніше).
