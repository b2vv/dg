# К6 — питання про оракул: чи потрібен новий метод містка

**Хто:** друга сесія `dg-62`. **Стан:** К6 у `main` ще немає (`main` @ `27dc8a5`), тож це рев'ю
**рішення**, не коду.

**Питання автора:** для проби «клік по chevron не виділяє» потрібен оракул; він додав
`getSelection()` у `window.__demoE2e` — у кроці, чий сенс саме злізти з містка. Чи можна дістати
оракул без нового методу?

**Відповідь: можна, і він уже є в DOM.**

---

## 1. Демо вже друкує виділення в `#status`

`App.ts:520-525` — на **кожен** `onSelectionChange`:

```
nodes.length === 0  →  `${tab} · 0 selected`
інакше              →  `selection · ${nodes.length} selected`
```

`#status` уже читають **чотири** спек-файли (`flat-orgs.spec.ts:49,60`, `demo-audit.spec.ts:55,83,
89,120,129`, `mockups.spec.ts:24`). Нового коду — нуль, нової поверхні — нуль.

⚠️ Bulk-бар (`[data-bulk="count"]`) для цього **не** годиться: він показується лише при
`nodes.length > 1` (`App.ts:662-667`), тобто на одиничному виділенні мовчить.

## 2. Якщо колись знадобиться програмний свідок — метод уже публічний

`getSelections()` існує на фасаді (`OrgHierarchyDiagram.ts:1371`) і описаний у `docs/USAGE.md:312`.
Тобто метод містка був би **дводворядковим форвардером до публічного API** — рівно та форма, яку
T119 крок 0 щойно видалив (`getLastContextMenu`).

## 3. 🔴 Але сам по собі `#status` оракулом ще не є

Проба «після кліку по chevron у статусі немає `selected`» **задовольняється зламаним оракулом**:
якщо `#status` не оновлюється взагалі, вона зелена. Це той самий клас, який цей цикл ловив тричі
(К1, К2, К5) — асерт, істинний і без фічі.

Тому оракул треба **оживити в тому самому прогоні**:

1. клік по `node-org-1-expander` → діти з'явились, `#status` **не** містить `selected`;
2. клік по `node-org-1` → `#status` містить `1 selected`.

Другий крок доводить, що перший асерт узагалі вміє впасти. Без нього проба доводить лише те, що її
написали.

---

## Про розрізнення «привід проти свідка»

Розрізнення правильне й варте того, щоб лишитись у звіті: місток як **привід** (спосіб зробити
дію) і місток як **свідок** (спосіб побачити наслідок) — різні ролі, і скорочувати треба першу.
Тут воно просто не потрібне: свідок уже стоїть у DOM і вже читається наявними пробами.

Якби `#status` не існувало, `getSelection()` у містку був би виправданим — і тоді цей абзац був би
про те, чому.
