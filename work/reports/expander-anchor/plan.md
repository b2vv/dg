## 2. Рішення, які план мусить ухвалити

### Д1. Клік по якорю — **новий метод `toggleOrg`**, а не поле `expanded`

Гейт (Г1) показав: обробник кліку в оверлеї **один на всі якорі** й кличе `focusByTestId`, який
виділяє вузол. Дві форми були на столі:

| | Що робить | Ціна |
|---|---|---|
| (а) якір несе `expanded`, оверлей сам обирає `expandOrg`/`collapseOrg` | нічого не додає до фасаду | росте публічний тип полем, якого хост не просив; оверлей стає розумним |
| **(б) `toggleOrg(orgId)` на фасаді** | оверлей лишається дурним | новий публічний метод ⇒ `USAGE.md` + CHANGELOG |

🔑 **Обрано (б)**, і вирішальний аргумент не в оверлеї: **у штату тогл є (`toggleStaffOrgExpand`),
у дерева немає.** Тобто (б) не додає поверхню, а **закриває наявну асиметрію** — рівно ту, за яку
цей репо вже платив у `0.4.1` (chevron знав про штат, дерево про дітей, а типи були різні).
Варіант (а) залишив би асиметрію й додав поле, яке ніхто не замовляв.

### Д2. `hasChildren` — необов'язкове, **лише для організацій**

Г3: `listTestAnchors` будує кандидатів з усіх боксів, а `NodeWorldBox.kind` буває
`person | organization | position`. Для персони питання не має відповіді; `false` там читалося б
як доведене «дітей немає». Отже поле **відсутнє** для інших `kind`, і це видно з `kind`, а не
вгадується.

### Д3. Бокс рахується **в момент монтування**, посилання не тримається

Гейт: `SceneRegistry.clear()` спорожняє реєстр на вході кадру, тож утримане посилання на
`expandButton` — об'єкт **минулого** кадру. Тому `OrganizationNodeView` кладе не контейнер, а
**плоскі числа** в координатах картки, і робить це там, де кнопка щойно змонтована.

### Д4. Промотований вузол бокса експандера **не віддає**

Г7: у `near-visible` Pixi-в'юха схована, бокси лишаються, шар якорів (`z 6`) над шаром promote
(`z 5`). Якір над схованою кнопкою клікав би в чужий HTML-компонент. Отже для промотованих
вузлів бокс не емітується.

## 3. Порядок робіт

```
К1  SceneRegistry + OrganizationNode: бокс кнопки в момент монтування, у локальних координатах
К2  DiagramRenderer: переносить у world, додає hasChildren; promote-виняток (Д4)
К3  nodeTestId + listTestAnchors: два нові поля в TestAnchorCandidate
К4  toggleOrg на фасаді (Д1) + USAGE §8
К5  createTestAnchorOverlay: другий якір + окрема гілка кліку через toggleOrg
К6  наш e2e flat-orgs переходить із window.__demoE2e на якір (A8, A9)
К7  USAGE §14: два поля, ТРИ стани відсутності, і гейт середовища (T115 крок 4)
К8  CHANGELOG + версія 0.5.0 + package-lock (він відстав на два релізи)
```

🔑 **Чому К1 перший, а не тип.** Найризикованіше припущення всієї задачі — що бокс кнопки взагалі
досяжний у придатних координатах. Гейт це підтвердив, але **на читанні коду**, не прогоном. Тому
першим кроком іде те, що це доводить: якщо координати виявляться непридатними, ми дізнаємось на
кроці 1 із двох файлів, а не на кроці 5 із семи.

⚠️ **К6 виконується після К5** і **не раніше**: доки якоря немає, `flat-orgs` не має на що
переходити.

## 5. План міграції

**Для хоста:** міграції немає — поля необов'язкові, метод новий. Хто нічого не міняв, не помічає
нічого.

**Для нас:** К1–К8 послідовно, кожен коміт лишає дерево зеленим. Коміти **явними шляхами**, не
`git add -A`: у дереві паралельно працює друга сесія.

⚠️ **Прогони — у файл, не через `| tail`.** Сьогодні це коштувало двом сесіям хибного висновку:
пайплайн ковтає код виходу (`false | tail -1` → `0`, `pipefail` off), а зріз хвоста ховає блок
падінь, який Playwright друкує **над** рядком `passed` ([T122](../../tasks/T122-e2e-can-under-run-silently-and-stay-green.md)).

## 6. Rollback

| Сценарій | Дія |
|---|---|
| Координати кнопки виявились непридатними | ловиться на **К1**, тобто до того, як щось публічне зрушило; revert одного коміту |
| Якір ламає наявні кліки по вузлу | К5 ізольований в оверлеї; revert одного файлу |
| `toggleOrg` виявився не тим API | ламально назад — тому він іде **окремим** кроком К4, а не всередині К5 |
| Хост скаже, що форма не та | поля необов'язкові ⇒ прибрати дешевше, ніж додати |

⚠️ **Що revert НЕ поверне:** запис у CHANGELOG і піднятий `0.5.0`. Версію відкочувати не можна —
вона вже опублікована фактом коміту; правильний хід — `0.5.1` із записом «прибрано».

## 7. Конституція (маніфест `## Конституція`)

- [x] **Тести перед кодом.** Кожен крок К1–К6 має тест **до** реалізації; для К5 це найважливіше —
      кейс «клік по якорю експандера не виділяє вузол» пишеться першим і мусить **червоніти** на
      нинішньому коді, бо нинішній обробник виділяє.
- [x] **KISS > SOLID.** Нової абстракції нема: два поля, один метод, одна гілка кліку.
- [x] **GoF — за фактом повторень.** Патернів не додаємо.
- [x] **Межа WASM ↔ TS.** Не чіпається.
- [x] **Публічний API не змінюється мовчки.** `USAGE.md` §8 (метод) і §14 (поля) — у тому ж циклі;
      CHANGELOG і версія — К8.
- [x] **Pocock — лише TS.** Rust тут відсутній.
